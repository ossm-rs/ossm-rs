# OSSM ESP32-S3 — XToys + Owner Control

Clean core package focused on the working XToys integration and owner controls.

Included:
- XToys BLE integration and firmware-owned XToys routine support
- Owner Wi-Fi page with persisted owner limits, machine settings, E-stop, BPM run and Wi-Fi setup
- Owner USB RX control path
- Existing OSSM motion/pattern engine and hardware support

Build and flash the ESP32-S3 firmware with the same project commands used for the previous working builds.
